# 초등 고학년 다중지능 체크리스트(128문항) 개발 × MatrAIx 시뮬레이션

학기 초 5~6학년에게 실시하는 다중지능(MI) 간이 체크리스트를 고치기 위한 사전 검토다.
현행 80문항(지능당 10)을 다듬고 신규 문항을 더해 **후보 192문항**(8개 지능 × 24, 흥미 12 + 능력 12)을
만든 뒤, **MatrAIx 연구팀의 공식 Survey 파이프라인**
([MatrAIx-ai/MatrAIx-Persona-8B](https://github.com/MatrAIx-ai/MatrAIx-Persona-8B), MIT)으로 검토하여
**최종 128문항**(지능당 16 = 흥미 8 + 능력 8)을 고른다.

## 연구 설계 요약

| 항목 | 내용 |
|---|---|
| 목적 | ① 현행 80문항의 지능 대응·5~6학년 이해도 점검 ② 128문항 검사지 개발 ③ 강점 지능 상위 3개가 안정적으로 나오는지 확인 (진로 활동 모둠 구성에 사용) |
| 성격 | 실제 학생 파일럿 **전** 사전 검토. 시뮬레이션은 실제 학생 검증을 대신하지 않는다 |
| 최종 검사지 | 8개 지능 × 16문항 = 128문항, 5점 척도, 답안지 8열 × 16줄 (열 합계 = 지능 점수), 64번 뒤 쉬는 칸 |
| 후보 묶음 | 192문항 = 기존 80문항 수정본 + 신규 112문항 → `items.md` |

## 수행 단계

| 단계 | 내용 | 파일 |
|---|---|---|
| 0. 기계적 점검 | 문장 길이(40자), '~보다' 비교형, '~거나' 이중 질문, 남의 평가, 낯선 낱말 표시 (LLM 없음) | `check_items.py` → `items.md` |
| 1. 후보 문항 | 기존 80문항 수정(원래 지능 열 유지) + 신규 112문항 | `mi_items.py` |
| 2. A1 전문가 분류 | 교사 페르소나가 **의도한 지능을 모르는 상태에서** 문항의 지능·측면을 고름. 4블록 × 48문항, 블록당 12명 | `build_tasks.py` |
| 3. A2 전문가 평가 | 다른 교사 패널이 의도한 지능을 보고 적합성(1~4)·5~6학년 이해 난이도(1~4) 평가 + 수정안 | `build_tasks.py` |
| 4. B 가상 학생 | 강점 1 + 다음 강점 2 + 약점 2를 심어 둔 5~6학년 96명이 192문항 전체에 응답 + 모르는 낱말·지루해진 지점 | `child_profiles.py`, `make_child_job.py` |
| 5. 문항 선정 | 기준을 넘는 문항 중 종합 점수 순으로 지능·측면마다 8개 → 128문항. 64문항 축약판과 판별 정확도 비교 | `report.py` |
| 6. 실제 파일럿 | 1~2개 학급 실시, 인지면접, 실시 시간·신뢰도 확인 (이 저장소 밖) | |

A1과 A2를 나눈 이유: 같은 설문에서 의도한 지능을 먼저 보면 분류가 그쪽으로 쏠린다.
같은 이유로 A1에는 후보 번호를 보여 주지 않는다. 후보 번호는 8개 지능 순서로 돌아가서(1 언어, 2 논리, …)
번호만 봐도 지능을 맞힐 수 있기 때문이다. A1은 블록 안에서 문항 순서를 섞고 1~48 표시 번호를 새로 붙이며,
질문 id에도 후보 번호를 넣지 않는다 (`build_tasks.a1_display`). 첫 시도에서 번호를 그대로 보여 줬더니
96문항 모두 일치율 100%가 나와, 그 결과는 버리고 이렇게 고쳤다.

### 페르소나

- **A (교사)**: MatrAIx Persona 1M에서 「당교한책」 연구의 표집 조건(`../matraix-dangyohanchaek/build_pool.py`:
  한국어 모국어 현직 교사, 학생·은퇴·프리랜서·대학 강사 제외, 남 30% : 여 70% 목표, 학교급=초등학교,
  근무 지역=서울·경기)을 그대로 쓰되, 문항을 판단할 경력이 있어야 하므로 경력 3년 이상 4개 구간
  (3-5, 6-10, 11-20, 20+)에서 6명씩 24명을 뽑는다 (`build_panel.py`). 경력·성별 칸마다 번갈아 나눠
  A1 패널 12명과 A2 패널 12명으로 쓴다 (서로 겹치지 않음).
- **B (학생)**: Persona 1M에는 아동 페르소나가 없어서 직접 만든다 (`child_profiles.py`). 프로필에는 지능 이름이나
  문항 문장을 쓰지 않고 생활 모습만 적는다 ("공책 귀퉁이마다 캐릭터 그림이 그려져 있다"). 답하는 성향도
  겸손/보통/후함 세 가지로 섞었다. 심어 둔 정답은 `child_profiles.json`에 있다.
  MatrAIx 공식 페르소나 YAML(v0: `system_prompt`)로 쓰고, 공식 스크립트로 1명짜리 job을 만든 뒤
  페르소나 목록만 바꾸므로 실행 환경은 공식 설정 그대로다.

### 문항 선정 기준 (`report.py` 맨 위에서 조정)

| 지표 | 출처 | 기준 |
|---|---|---|
| 지능 일치율 | A1: 의도한 지능을 고른 교사 비율 | ≥ 50% |
| I-CVI | A2: 적합성 3~4점 비율 | ≥ 0.78 |
| 이해 난이도 | A2: 평균 (1~4) | ≥ 3.0 |
| 수정된 문항-총점 상관 | B: 같은 지능 나머지 23문항 합과의 상관 | ≥ 0.2 |
| 변별도 | B: 그 지능이 강점인 아이와 아닌 아이의 평균 차 | 종합 점수에만 반영 |
| 모름 표시 비율 | B: 그 문항 번호를 '모르는 낱말'에 적은 아이 비율 | 종합 점수에서 감점 |

기준을 넘는 문항이 8개보다 적은 지능·측면은 기준 미달 문항으로 채우고 보고서에 빨간 글씨로 표시한다.
그런 문항은 실제 파일럿 전에 고쳐 쓴다.

## 실행

```bash
export ANTHROPIC_API_KEY=...        # 채팅이나 저장소에 붙여 넣지 말 것
                                    # (Claude Code 클라우드 환경에서는 MATRAIX_ANTHROPIC_API_KEY 이름도 가능)
PANEL_LIMIT=2 CHILDREN=3 BLOCKS=1 RUN_TAG=smoke ./run_all.sh   # 시험 실행 (보고서는 report-smoke/)
./run_all.sh                        # 본 실행: A1 48회 + A2 48회 + B 96회 = 192회
PARTS="B" ./run_all.sh              # 일부만 (BLOCKS="2 3"처럼 블록도 고를 수 있음)
```

비용 상한은 A job마다 `MAX_COST_USD`(기본 $5), B job은 `MAX_COST_B`(기본 $25)다. 시험 실행에서 잰 비용은
교사 1명당 A1 약 $0.14, A2 약 $0.09, 가상 학생 1명당 약 $0.12였으므로 본 실행은 약 $23이 든다.
같은 이름의 job이 남아 있으면 이어서 실행하므로, 실패한 job을 새로 돌릴 때는 `RUN_TAG`를 바꾸거나
`<matraix>/jobs/<job>`을 지운다.

## 파일

| 파일 | 역할 |
|---|---|
| `mi_items.py` | 현행 80문항 원문, 수정본과 수정 사유, 신규 112문항 |
| `items.md` | 사람이 읽는 후보 문항표 (`check_items.py`가 생성) |
| `check_items.py` | 0단계 기계적 점검 |
| `build_panel.py` | 서울·경기 초등교사 패널 24명 → A1·A2 패널 12명씩 |

## 해석할 때 주의할 점

- 결과는 LLM이 페르소나를 연기한 **시뮬레이션**이다. 문항을 미리 거르는 데 쓰고, 실제 학생 파일럿으로 확인한다.
- LLM이 연기하는 아이는 실제 아이만큼 낱말을 모르지 않는다. 이해도는 A2 교사 평가와 실제 파일럿으로 판단하고,
  B는 주로 문항이 의도한 지능에 반응하는지 보는 데 쓴다.
- 가상 학생의 지루함 응답은 참고만 한다. 128문항의 실제 피로도는 파일럿에서 실시 시간과 후반부 응답
  (같은 번호를 연달아 고르는지)으로 확인한다.
- 교사 페르소나에는 국가·학교급 속성이 없다. `role_function = Teaching`에는 중고등·대학 교사가 섞일 수 있어
  과제 안내에서 "초등 5~6학년 담임의 관점"으로 판단하도록 했다.
- MI 검사는 진단 도구가 아니라 자기 이해와 진로 탐색 도구로 쓴다. 실제 학생 자료를 연구에 쓸 때는 학부모
  동의 절차를 거친다.
