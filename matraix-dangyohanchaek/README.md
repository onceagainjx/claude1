# 「당교한책」 질문 세트 × MatrAIx 경력별 시뮬레이션

「저경력 교사 나답게 가르치기(가칭)」 개발을 위해, 기존 「당교한책」 「워크북: 나의 이야기」 편의
여섯 여정 질문(40개)을 **MatrAIx 연구팀의 공식 Survey 파이프라인**
([MatrAIx-ai/MatrAIx-Persona-8B](https://github.com/MatrAIx-ai/MatrAIx-Persona-8B), MIT)으로
가상 교사들에게 일괄 적용하고, 저경력과 고경력의 반응을 비교한다.

## 무엇을 묻나

여정마다 하나의 Survey 과제를 만든다 (총 6개).

| 구분 | 문항 | 형식 |
|---|---|---|
| 원 질문 | 워크북의 여는·잇는·깊은 질문을 원문 그대로 | 서술형 (2~4문장) |
| 질문별 평가 | "이 질문에 나의 실제 경험으로 답하기가 얼마나 쉬웠나요?" | 1~10 척도 |
| | 이 질문에 답하기 어려웠던 가장 큰 이유 (경험 부족, 전제 불일치, 사적임, 추상적, 생존 우선, 어렵지 않음) + 이유 서술 | 단일 선택 |
| 여정 평가 | 의미 / 심리적 부담 / 지금 연차에 적절한 시기인가 | 1~10 척도 |
| | 5년 차 이하 교사용 질문 수정안 / 지금 다루고 싶은 이야기 | 서술형 |

모든 서술형 답과 이유는 페르소나의 주 언어와 관계없이 한국어로 쓰도록 지시한다.

## 누구에게 묻나

**서울·경기 초등교사**를 가정한다. `build_pool.py`가 MatrAIx Persona 1M 공개 데이터에서 공식 표집기로
다음 페르소나를 뽑아 하나의 묶음으로 만들고, 모든 여정에 같은 페르소나를 쓴다.

| 조건 | 방법 |
|---|---|
| 현직 교사, 한국어 모국어 | 스키마 속성으로 거름: `role_function = Teaching`, `region = East Asia`, `lang_korean = Native`, `primary_language = Korean`, `life_stage`에서 학생·은퇴 제외, `company_size`가 프리랜서·대학(학원·과외·대학 강사로 보임)인 페르소나 제외 |
| 경력 | `years_experience` 5개 구간(0-2, 3-5, 6-10, 11-20, 20+)에서 같은 수 (기본: 구간당 10명, 여정당 50명) |
| 남 30% : 여 70% | 구간마다 `gender_identity`별로 따로 뽑음 (구간당 10명이면 남 3, 여 7). 후보가 모자란 칸은 다른 성별로 채움 |
| 학교급 = 초등학교 | 스키마에 없는 속성(overlay)으로 모든 페르소나에 붙임 |
| 근무 지역 = 서울·경기 | overlay로 경력·성별 칸마다 반반 나눠 붙임 |

한국식 이름(성별에 맞춤)도 붙인다. 보고서에서는 0~5년을 **저경력**, 11년 이상을 **고경력**으로 묶어 비교한다.

## 실행

```bash
export ANTHROPIC_API_KEY=...      # 채팅이나 저장소에 붙여 넣지 말 것
                                  # (Claude Code 클라우드 환경에서는 MATRAIX_ANTHROPIC_API_KEY 이름도 가능)
SAMPLE_SIZE=10 ./run_all.sh       # 시험 실행: 여정당 10명
./run_all.sh                      # 본 실행: 여정당 50명 × 6개 여정 = 300회
```

`run_all.sh`가 하는 일:

1. 공식 저장소 클론과 `uv sync`
2. Persona 1M 공개 데이터 다운로드 (huggingface.co, 최초 1회)
3. `build_tasks.py`로 6개 Survey 과제 생성
4. 여정마다 공식 `generate_application_job.py`로 표집한 뒤 `matraix run`으로 일괄 실행. 여정당 비용 상한은
   `MAX_COST_USD`(기본 $5)
5. `report.py`로 `report/report.html`(비교 보고서)과 `report/answers.csv`(원자료) 생성

## 보고서 구성 (`report/report.html`)

1. 여정별 요약: 여정마다 의미·부담·시기 적절성, 그리고 여정의 질문 목록과 질문별 분석(답하기 쉬움,
   어려웠다는 비율, 주된 이유를 한 문장으로)
2. 재설계 우선순위: 저경력이 고경력보다 답하기 어려워한 질문 순위와 질문마다 저경력의 대표 이유 2개
3. 어려움의 이유: 이유마다 저경력·고경력이 어떤 여정의 어떤 질문에서 그 이유를 골랐는지
4. 저경력 페르소나의 목소리: 질문 수정 제안, 질문별 어려움의 이유
5. 저경력 페르소나가 다루고 싶은 이야기
6. 같은 질문에 대한 저경력/고경력 응답 예시

한국어가 아닌 서술이 섞이면 보고서 머리글에 개수를 적고 해당 응답에 '[한국어 아님]'을 표시한다.

## 파일

| 파일 | 역할 |
|---|---|
| `journeys.py` | 프로그램 전제와 여섯 여정 질문 세트 (원문: 「당교한책」 해설서 4장·6장) |
| `build_tasks.py` | 질문 세트 → MatrAIx 공식 Survey 과제 폴더 |
| `build_pool.py` | Persona 1M → 서울·경기 초등교사 페르소나 묶음 (성별 비율, 학교급, 근무 지역) |
| `run_all.sh` | 전체 실행 |
| `report.py` | 결과 → 경력 집단 비교 보고서 |
| `test_pipeline.py` | 과제 생성과 보고서 점검 (가짜 데이터, API 호출 없음) |

## 해석할 때 주의할 점

- 결과는 LLM이 페르소나를 연기한 **시뮬레이션**이다. 재설계 가설을 세우는 데 쓰고, 실제 저경력 교사
  파일럿으로 확인한다.
- 페르소나에는 국가 속성이 없다(지역은 `region`까지만 있음). 그래서 한국어가 모국어인 동아시아 교사
  페르소나를 골랐다. 학교급과 근무 지역은 표집 뒤에 페르소나 설명에 한 줄로 덧붙인 속성이라, 원래 페르소나
  이야기(전공, 근무 기관 등)와 어긋날 수 있다.
- 3~5년 여교사 후보가 3명뿐이라 그 구간은 남 7, 여 3으로 뽑힌다. 기본 설정(구간당 10명)의 전체 성비는
  남 19 : 여 31 (38:62)이다.
- 시험 실행(`SAMPLE_SIZE=10`, 구간당 2명)으로는 남 30% : 여 70%를 맞출 수 없다(남 1, 여 1).
- 여는글 원문은 넣지 않고 핵심만 요약해 문항에 담았다. 실제 회차의 여는글 체험과는 다르다.
- 6번째 여정의 "여섯 번의 여정으로 무엇을 알게 되었나요?"는 단독 설문에서는 앞선 여정을 겪지 않았으므로
  "이 회차의 질문에 답하며 알게 된 것"으로 답해도 된다는 안내를 덧붙였다.
